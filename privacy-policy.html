🚚 Política de Privacidade — Frete Legal

Última atualização: 3 de maio de 2026

1. Quem somos

O aplicativo Frete Legal é uma ferramenta de cálculo do piso mínimo de frete rodoviário de cargas, desenvolvida para auxiliar caminhoneiros autônomos e transportadores no cumprimento da tabela oficial da ANTT (Agência Nacional de Transportes Terrestres).

2. Dados que coletamos

2.1 Dados fornecidos voluntariamente

  • Nome do usuário (opcional, salvo apenas no dispositivo)
  • Placa do veículo (opcional, salvo apenas no dispositivo)
  • Configurações de perfil (eixos padrão, tipo de carga)

2.2 Dados gerados automaticamente

  • Histórico de fretes calculados (salvo apenas no dispositivo local)
  • Preferências do aplicativo

2.3 Dados NÃO coletados

  • Não coletamos dados de localização GPS
  • Não coletamos dados de identificação pessoal (CPF, RG, etc.)
  • Não coletamos dados financeiros ou bancários
  • Não compartilhamos dados com terceiros para fins comerciais

3. Como usamos os dados

Dado Finalidade Onde fica
Nome e placa Personalização da interface Apenas no seu dispositivo
Histórico de cálculos Consulta futura dos fretes calculados Apenas no seu dispositivo

4. APIs de terceiros utilizadas

4.1 OpenStreetMap — Nominatim e OSRM

  • Finalidade: Busca de cidades e cálculo de distância por rodovia
  • Dados enviados: Nome das cidades digitadas pelo usuário
  • Política: openstreetmap.org/copyright
  • Armazenamento: Nenhum — as consultas são temporárias

4.2 Google AdMob (Google)

  • Finalidade: Exibir anúncios na versão gratuita do aplicativo
  • Dados enviados: Identificadores de publicidade e dados técnicos do dispositivo, conforme políticas do Google
  • Política: policies.google.com/privacy

4.3 Google Play Billing (Compras no app)

  • Finalidade: Processar compra e restauração da versão Pro
  • Dados enviados: Informações de transação necessárias para validar a compra no ecossistema Google Play
  • Política: policies.google.com/privacy

5. Armazenamento e segurança

Todos os dados pessoais são armazenados exclusivamente no dispositivo do usuário usando armazenamento local seguro (SharedPreferences criptografado no Android). Não mantemos servidores com dados pessoais dos usuários.

6. Seus direitos (LGPD — Lei 13.709/2018)

Conforme a Lei Geral de Proteção de Dados Pessoais, você tem direito a:

  • Acesso: visualizar seus dados nas configurações do app
  • Correção: editar qualquer informação nas configurações do perfil
  • Exclusão: apagar todos os dados locais desinstalando o aplicativo ou limpando o histórico nas configurações
  • Portabilidade: exportar o histórico de cálculos (funcionalidade em desenvolvimento)

7. Retenção de dados

Os dados são mantidos enquanto o aplicativo estiver instalado no dispositivo. A desinstalação remove todos os dados locais automaticamente.

8. Crianças

Este aplicativo não é direcionado a menores de 18 anos e não coletamos intencionalmente dados de crianças.

9. Alterações nesta política

Mudanças significativas serão comunicadas por notificação no próprio aplicativo. A data da última atualização é exibida no topo desta página.
